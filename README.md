# Scalable-Static-Website-with-S3-Cloudflare-GitHub-Actions

Objective: Host and auto-deploy a static website using S3 (free tier) with global CDN and HTTPS via Cloudflare, triggered through GitHub commits.

Tools: AWS S3 (Free), Cloudflare (Free), GitHub Actions, HTML/CSS, Bash

Mini Guide: 
1. Create a static HTML site and push to GitHub.
2. Set up GitHub Actions to sync content to an S3 bucket.
3. Connect S3 to a custom domain via Cloudflare and enable SSL.
4. Add cache settings and versioning.
  
Deliverables: 
1. GitHub Actions CI/CD workflow
2. Cloudflare + S3 integration steps
3. Live website link with HTTPS
4. Screenshot + deployment report
